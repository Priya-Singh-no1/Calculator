
This project is a basic calculator implemented in JavaScript. It allows users to perform simple arithmetic operations using a web interface.

## Features

- Addition, subtraction, multiplication, division
- Clear all input (`AC`)
- Delete last character (`DEL`)
- Calculate result (`=`)

## Usage

1. Open the HTML file containing the calculator interface.
2. The calculator buttons interact with the logic in `calculator.js`.
3. Click buttons to enter numbers and operators.
4. Use `DEL` to remove the last character, `AC` to clear all input, and `=` to evaluate the expression.

## File Structure

- `calculator.js`: Contains the main logic for button interactions and calculation.
- `index.html`: Should contain the calculator UI with buttons and an input box with `id="inputBox"`.
